# Proyecto Docker de Juan Gubio 🚀

## Descripción
Aplicación simple en Flask desplegada como contenedor Docker.

## Cómo ejecutar localmente
```bash
docker build -t juangubio:1.0.1 .
docker run -p 8080:8080 juangubio:1.0.1
```
